# 💥 X-Hype Crafter | 推特卧槽体 · 网感短推熔炉

> **专为推特 / X 打造的高网感短推生成工具**。拒绝爹味与温吞说教，一键把平淡素材锻造成情绪炸裂、短句留白、充满「我操！直接跪了」的推特爆款推文。

---

## ✨ 核心特性

### 1. 🤯 卧槽指数 & 情绪拉杆 (Hype Slider Lv.1 ~ Lv.5)
- **Lv.1 理智极客**：客观、专业、带一点推特特有的反思与洞察，克制但有杀伤力（“有点意思，值得深思”）
- **Lv.2 推特老KOL**：信息量密集、黄金短句留白、收割收藏夹（“时代真的变了，很多人还没意识到”）
- **Lv.3 卧槽狂暴**：口头禅必带“我操/卧槽/真特么神了”，感叹号密集，见证历史，头皮发麻
- **Lv.4 疯狗核爆**：“我操我操我操！连夜把键盘敲烂，友商连夜爬上天台”，情绪达到顶峰
- **Lv.5 毒舌嘴替**：互联网嘴替，嘲讽拉满，撕下遮羞布（“笑死我了，底裤都被扒光了，纯纯智商税大冤种”）

### 2. 🔥 6 大推特成熟爆款流派
1. **🤯 卧槽震撼流**：见证历史 / 科技奇迹 / 刚测完直接给跪
2. **🔥 暴论颠覆流**：反常识 / 掀桌子 / 99%的人认知都是错的
3. **🍿 辛辣嘴替流**：互联网嘴替 / 吃瓜阴阳 / 纯纯大冤种
4. **🧵 干货清单流**：信息差 / 建议先存防和谐 / 连夜整理出来
5. **💰 暴富FOMO流**：错过拍断大腿 / 普通人最后的窗口期 / 闭眼冲
6. **🧨 极简一击流**：字少事大 / 极其克制但刀刀见血 / 单句杀手

### 3. ⚡️ 双生成引擎 (Dual Engine)
- **内置离线秒级引擎**：无需任何 API Key，内置丰富的推特黑话库与动态语料算法，输入主题后毫秒级输出 3 条不同视角推文。
- **AI 大模型强化引擎**：支持接入任何 OpenAI 兼容 API（DeepSeek / OpenAI / Claude / Moonshot / 本地 Ollama），搭载精心调优的《推特顶级爆款 Master Prompt》，生成独一无二的高质量网感神推。
- **自带 Master Prompt 库**：不想配置 API Key 也无所谓，支持一键复制神级提示词直接粘贴到 ChatGPT / Claude / DeepSeek 网页端使用。

### 4. 𝕏 推特原味预览与工具箱
- **推特官方 280 字符精准检测**：根据推特官方规则（中文字符/Emoji 计为 2，英文字符计为 1，网址计为 23）实时进度条显示与超长预警。
- **推特拟真卡片**：模拟真实发帖界面（支持自定义头像、昵称、@handle、蓝V认证标、互动数据）。
- **一键复制**：保留推特留白换行排版，复制带礼花反馈。
- **一键直发推特**：点击自动调用 `twitter.com/intent/tweet` 填充内容，极速发布。
- **导出高清卡片长图**：内置 HTML-to-Image 引擎，一键下载高分辨率推文卡片图片，便于转发小红书、微博、朋友圈、即刻等社媒。
- **推特黑话连招托盘**：涵盖“情绪暴击”、“颠覆认知”、“嘴替锐评”、“价值收割”数十个爆款热词，点击直接插入素材。

## 🚀 极速启动

```bash
# 1. 进入项目目录
cd /Users/liangxiaoling/.gemini/antigravity/scratch/x-hype-crafter

# 2. 启动本地开发服务器
npm run dev
```

启动后在浏览器打开终端提示的地址（默认 `http://localhost:5173`）即可使用！

- **图像导出**: html-to-image
